# Professional AI Development Prompt

## Project Name: ugSOT Newsletter Management System

I want you to build a complete professional web application for my company named **upGrad School Of Technology (ugSOT)**.

The purpose of this application is to manage and distribute company newsletters to all employees automatically through email.

The application must be scalable, production-ready, cleanly structured, and follow industry-standard best practices for both frontend and backend architecture.

---

# Core Objective

Our company publishes a newsletter every 15 days.

We maintain an Excel sheet containing:

* Employee Name
* Employee Email Address

The system should allow admins to:

1. Upload employee Excel sheet
2. Store employee data in Supabase
3. Upload newsletter PDFs
4. Send automated emails to all employees
5. Attach the newsletter PDF inside the email
6. Use a professional email template
7. Manage newsletters from a clean admin dashboard

---

# Important Authentication Requirement

This website is ONLY for internal admin usage.

There will NOT be:

* Employee login
* Employee signup
* Multi-role system
* Complex authentication system

Implement a very simple admin authentication system using:

* Email
* Password

Requirements:

* Single admin login page
* Protected admin dashboard routes
* Secure session handling
* Logout functionality
* Persistent login session

The admin credentials can be stored securely in:

* Environment variables
  OR
* A simple admin table in Supabase

DO NOT use:

* Supabase Auth
* OAuth
* Google Login
* Social Authentication
* RBAC systems

Keep the authentication lightweight, simple, and easy to maintain.
